# Synchronous Analysis of Speech Production and Lips Movement to Detect Parkinson’s Disease Using Deep Learning Methods

This repository contains the implementation of a synchronous multimodal fusion approach for Parkinson's disease (PD) assessment using speech and facial information. The proposed framework combines representations extracted from audio and video (lips) while preserving their temporal correspondence, enabling the model to jointly exploit complementary information from both modalities for PD classification.

Repository Structure

The main components of the repository are located in the models/ folder. This directory contains the architectures used in the experiments, including the unimodal models and the proposed synchronous fusion block used to combine the audio and video representations.
